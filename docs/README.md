## Arranque de sesión

1. Leer `AGENTS.md`.
2. Leer `HANDOVER.md`.
3. Leer `PROJECT_STATUS.md`.
4. Leer `NEXT_SESSION.md`.
5. Leer la última `SESSION-XXX.md`.

## Cierre de sesión

Actualizar `HANDOVER.md`, `CHANGELOG.md`, `PROJECT_STATUS.md`, `NEXT_SESSION.md` y escribir `SESSION-XXX.md`.
